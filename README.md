Aplicação web desenvolvida para o **Salão Belíssima** (Salão, Perfumaria e Cosméticos — Taboão da Serra, SP), reunindo agendamento online em 4 etapas, catálogo segmentado por especialista, boutique de produtos e painel administrativo.
**JavaScript (ES6+):** Lógica de negócio, filtros dinâmicos, máscaras de entrada, manipulação de datas, persistência local (`localStorage` / `sessionStorage`) e compressão de imagens via Canvas API.
* **React (JSX):** Componentização e gerenciamento de estado com Hooks (`useState`, `useEffect`, `useMemo`).
* **Tailwind CSS:** Interface responsiva mobile-first, gradientes e tema escuro personalizado.
* **SVG Vetorial:** Ilustrações customizadas para o logotipo oficial, frascos de cosméticos e ícones dos serviços.
